# Своя тарелка

Планировщик меню на неделю и списка покупок. Для локальной проверки запустите
в корне `python3 -m http.server` и откройте `http://localhost:8000`.
Для GitHub Pages выберите публикацию из `main`, папка `/(root)`.

## Как строится меню

Подбор использует все ответы анкеты. Магазин определяет цены из справочника
`prices-tyumen.js` и набор ручных цен. Бюджет проверяется по стоимости
общей корзины, включая целые упаковки. По выбранным приёмам пищи сайт
выбирает по одному блюду на каждый день.

На приёмы «на всю семью» рассчитываются взрослые и детские порции.
Коэффициенты детской порции: 0,5 до 7 лет, 0,75 с 7 до 12 лет, 1 с 13 лет.
Остальные приёмы рассчитаны на одну порцию. Коэффициенты нужны для расчёта
закупки. Аллергены и исключённые продукты удаляют блюда из подбора.
Рецепт доступен, если хотя бы один способ приготовления подходит под
выбранную технику.

Подбор строит два недорогих варианта и пробует заменить отдельные блюда
с учётом стоимости общей корзины. Если корзина укладывается в бюджет, он
старается уменьшить число повторов. Если подходящий план в рамках суммы
не найден или для приёма пищи нет рецептов, результат сообщает об этом.

## Каталог и цены

`recipes.json` хранит продукты и рецепты. Ключи `ingredients` — идентификаторы
продуктов из `products`, значения — граммы на одну порцию. В `methods`
указаны обязательные приборы и шаги приготовления. Пустой список приборов
означает способ без указанной техники. Архив распознанных меню хранится
отдельно в `menus/`.

В расчёте приоритет у ручных цен выбранного магазина, затем у цен с
источником, затем у явно помеченной справочной оценки. Цены и фасовку
можно уточнить в списке покупок. Сайт хранит ручные цены отдельно для
каждого магазина в браузере. Граммовки, фасовки без подтверждения и
справочные цены служат для планирования закупки.
