# Своя тарелка

Планировщик меню и покупок. Для публикации через GitHub Pages загрузите содержимое архива в корень репозитория. В Settings → Pages выберите Deploy from a branch, main, /(root) и нажмите Save.

## Каталог меню

Планировщик загружает `menus.json` из корня сайта. В каталоге два варианта
рациона («Лайт» и «Детокс») с 31 мая по 13 июня 2021 года. Для каждого меню
указаны имя файла и страница источника. Внутри каждого приёма пищи:

- `dishes` — блюда, входящие в меню.
- `hotChoices` — альтернативные горячие блюда, из которых выбирают одно.
- `servingG` — выход порции или её компонентов в граммах, в порядке из PDF.
- `nutrition` — белки, жиры, углеводы и калорийность на порцию.
- `sourceSubtotal` — итог приёма пищи, если он приведён в меню.
- `ingredients` — состав, указанный в PDF. Пустой массив означает, что
  отдельного списка ингредиентов нет.

Граммовки ингредиентов и шаги приготовления в PDF отсутствуют. Список
покупок собирается по указанному составу без расчёта количества и цены.
Для локальной проверки запустите в корне репозитория `python3 -m http.server`
и откройте `http://localhost:8000`.
